# Security

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and select **Report a vulnerability**. Only the maintainer can read the report.

Examples of what to report privately: a way for one person to read or change another person's tickets, a way past the Gmail Private install's sign-in check, a way to run script on the Verlass website or in the add-ins, or a way to obtain someone's Microsoft 365 or Google sign-in.

Supported version: the latest release on the `main` branch. Verlass has no server of its own, so a fix reaches Outlook users as soon as the website is updated, and Gmail users when they replace their script files.

Everything else, including ordinary bugs and questions, is welcome as a [public issue](https://github.com/alyssaagard/verlass/issues).
